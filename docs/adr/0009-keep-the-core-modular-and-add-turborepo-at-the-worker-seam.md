# Keep the core modular and add Turborepo at the worker seam

Keep authoritative HR behavior in one deployable modular monolith, organized as business-capability modules with deep interfaces while Next.js remains a delivery adapter. When MVP-009 introduces the independently runnable integration worker, migrate to Bun workspaces orchestrated by Turborepo, starting with `apps/web`, `apps/integration-worker`, `packages/hr-core`, `packages/persistence`, and `packages/event-contracts` rather than generic shared or package-per-feature libraries. Nx and service-per-module decomposition add machinery before this solo/small-team product needs it, so a module becomes an independent service only when concrete scaling, deployment, availability, security, technology, or ownership pressure justifies extraction.
